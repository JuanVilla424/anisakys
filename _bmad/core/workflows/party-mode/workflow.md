# Party Mode Workflow

## Multi-Agent Collaboration Session

**Purpose**: Facilitate group discussions with multiple specialized agents for comprehensive problem-solving and brainstorming.

## Overview

Party Mode brings together multiple expert agents to collaborate on complex challenges, enabling diverse perspectives and expertise to converge on solutions.

## Workflow Steps

### 1. Identify Participants

- Review the topic/challenge at hand
- Determine which agent personas would provide valuable input
- Available agents: PM, Architect, Developer, UX Designer, Analyst, Scrum Master, Tech Writer

### 2. Set Discussion Context

- Clearly state the problem or question
- Define desired outcomes
- Establish any constraints or requirements

### 3. Facilitate Discussion

- Each agent contributes from their expertise area
- Encourage cross-pollination of ideas
- Build on each other's suggestions
- Challenge assumptions constructively

### 4. Synthesize Results

- Summarize key insights from each perspective
- Identify consensus and divergent views
- Document actionable recommendations
- Assign next steps if applicable

## Agent Roles in Party Mode

| Agent                   | Primary Contribution                                            |
| ----------------------- | --------------------------------------------------------------- |
| **PM (John)**           | Business value, prioritization, user impact                     |
| **Architect (Winston)** | Technical feasibility, system design, scalability               |
| **Developer (Amelia)**  | Implementation details, effort estimates, technical constraints |
| **UX Designer (Sally)** | User experience, interface design, usability                    |
| **Analyst (Mary)**      | Data insights, requirements clarity, market context             |
| **Scrum Master (Bob)**  | Process, story breakdown, team coordination                     |
| **Tech Writer (Paige)** | Documentation needs, clarity, knowledge transfer                |

## Best Practices

- Keep discussions focused on the stated objective
- Ensure all voices are heard
- Document decisions and rationale
- Follow up with concrete action items

## Example Use Cases

- Feature planning and architecture decisions
- Problem-solving complex technical challenges
- Sprint planning and story breakdown
- Design reviews and UX validation
- Project kickoff and requirement gathering
